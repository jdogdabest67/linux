🐧 JoyGPT Linux Lab

A mobile-friendly launchpad for a real browser Linux environment. The command box below is a diagnostics console, not a fake Linux shell. The embedded Linux runtime is separate and may have browser/sandbox limits.

1. Browser & network capabilities

Checking browser capabilities…

Device pickers only list compatible USB/serial devices actually attached and exposed to the browser. Opening a picker is not a connection to the Switch.

2. Run diagnostics

joygpt@browser:~$ help
Welcome. Type help, capabilities, or open-linux. These are browser diagnostics, not a real shell.

This console only runs the listed safe diagnostics. It cannot execute arbitrary Linux commands.

3. Launch browser Linux

Try the external WebVM Linux environment. It runs in the browser sandbox, not on your phone's Wi-Fi hardware. If embedding is blocked, open it in a new tab.

Open WebVM in new tab ↗

If the frame stays blank or reports a security error, use the new-tab link. WebVM may restrict embedding.

4. What this can and cannot test

Can: check browser APIs, launch a browser Linux runtime, and see what that runtime exposes.
Cannot assume: access to Android's physical Wi-Fi adapter, raw 802.11 action-frame transmission, or Splatoon LDN authentication.
A cloud/virtual Linux network interface is not the same as the phone's physical radio. We'll only claim a live connection if a real exchange is observed.

No data is uploaded by this page. Device picker buttons only request browser chooser dialogs; this page does not read or transmit device data.
