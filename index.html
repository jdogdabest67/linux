Why the two tempting routes do not solve it

Super Mario Odyssey + GameShare

Great match for Cappy: the second player controls Cappy. But GameShare guests join from a second Switch or Switch 2 system, not a phone browser. It needs a second console.

PhantomHand browser controller

Its setup guide calls for an Arduino Leonardo plus a separate serial adapter. The guide says phones/tablets are not supported (Android may work but was not tested) and describes desktop Chrome setup. The hardware bridge is the missing part.

9. Research: possible paths into a real game

The browser tests have answered the easy part: the page can receive some controller-related events and the phone can send messages to the page. The missing step is converting a remote command into a controller input that the running game accepts.

Browser-only JavaScript

Not a complete route. Synthetic keyboard/click events are events inside the webpage, not hardware controller reports. The Switch page also reported WebUSB, WebHID, and Web Bluetooth unavailable, with no visible Gamepad device or Nintendo applet API.

External USB controller bridge (strongest documented route)

Phone/browser → Worker/WebSocket → a separate microcontroller or controller-bridge device → USB controller input to the console. PhantomHand documents an ATmega32U4 Arduino Leonardo plus a serial adapter and NintendoSwitchControlLibrary. This is documented for Switch automation; Switch 2 compatibility with that exact library/hardware is not confirmed, so it needs a safe compatibility test before we rely on it.

PhantomHand architecture ↗ · Controller library ↗

Phone as a Bluetooth HID device

Android has a native BluetoothHidDevice API, but it requires a native app and Bluetooth permissions; a normal browser page cannot register the phone as a Bluetooth HID controller. It is not viable under the current browser-only/managed-phone constraints, and Nintendo-controller compatibility is unverified.

Android Bluetooth HID API docs ↗

Linux Bluetooth controller emulation

A Linux computer with a compatible Bluetooth adapter may be able to emulate a Switch controller using projects such as joycontrol, but Switch 2 support is uncertain. The old desktop's condition and Bluetooth hardware would need checking first.
