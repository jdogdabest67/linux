The mission: let ChatGPT help play a real Switch game, starting with Cappy in Super Mario Odyssey. This page now contains only tests that can tell us something useful with the gear currently available.

Current reality check

We have not connected ChatGPT to the Switch. A web page can read input from a controller that the phone exposes to it, but that does not make the phone a Switch-compatible controller or forward commands into the console.

The previous USB initialization test, pretend C encoder, and PhantomHand packet simulator have been removed from the page. They did not create a working control path, and probing the Pro Controller could interrupt its connection.

Why the two tempting routes do not solve it

Super Mario Odyssey + GameShare

Great match for Cappy: the second player controls Cappy. But GameShare guests join from a second Switch or Switch 2 system, not a phone browser. It needs a second console.

Nintendo's official Odyssey multiplayer steps ↗

PhantomHand browser controller

Its setup guide calls for an Arduino Leonardo plus a separate serial adapter. The guide says phones/tablets are not supported (Android may work but was not tested) and describes desktop Chrome setup. The hardware bridge is the missing part.

Phone USB-C directly to Switch

In our test, Android showed file-transfer/tether/MIDI/charging options and the console did not become a controller bridge. A browser page cannot turn that cable into a USB controller emulator by itself.

What to test now

First: tap Scan again and note whether WebUSB, WebHID, Web Bluetooth, and Gamepad API say “Exposed” or “Not exposed.”

Then, only if useful: start the input monitor with a controller connected to the phone and tell me whether any buttons/axes change. If no controller is attached to the phone, “No controller detected” is an expected result, not a failure.

These checks can rule out browser-side options. They will not make the Switch respond. With current hardware, the missing ingredient is a real control path between the browser/ChatGPT and the console.
