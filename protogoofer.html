PROTOGOOFER

A tiny enemy-randomizer workbench for the Chapter 1 Dark World. Roll new encounter lineups, lock in a seed, and export the shuffle plan.

Prototype status: This version randomizes encounter lineups and exports a JSON plan. It does not yet patch the Deltarune web port or change enemies inside the running game. The port uses a compiled GameMaker runtime, so direct in-game randomization needs a separate game-data patching step.
