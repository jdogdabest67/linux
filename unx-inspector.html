UNX Inspector

Read-only look inside a GameMaker data file (game.unx, data.win). Files are read in your browser only and never uploaded or modified.



Supported: chunk table, GEN8 summary, name lists for objects, scripts, rooms, code, sprites, sounds and a few others, plus the string table. Chunks marked recognized-unparsed or unknown are listed but not read. Code tab: references (calls, variables, strings) are resolved from compiled bytecode and verified per file; this is not a GML decompiler. Not supported: object event tables, GML decompiling, textures, audio, exact version detection, editing or patching. Layouts follow public format docs and are checked against real data only when you load a real file; watch the warnings above.
